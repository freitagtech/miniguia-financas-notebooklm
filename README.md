# 4. Miniguia de Estudo (Entrega Final)

## 4.1 Resumo Estruturado

### O que são Finanças Pessoais?

Finanças pessoais representam a gestão do dinheiro de um indivíduo ou família, envolvendo:

* Receitas;
* Despesas;
* Poupança;
* Investimentos;
* Planejamento financeiro.

---

### Orçamento Financeiro

É o registro e controle de todas as entradas e saídas de dinheiro.

Passos básicos:

1. Identificar receitas;
2. Registrar despesas;
3. Separar gastos fixos e variáveis;
4. Definir metas financeiras;
5. Monitorar regularmente.

---

### Reserva de Emergência

É um valor guardado para situações inesperadas.

Exemplos:

* Desemprego;
* Problemas de saúde;
* Reparos urgentes.

Recomendação geral:

* Acumular entre 3 e 6 meses das despesas mensais.

---

### Investimentos para Iniciantes

Principais alternativas:

#### Poupança

* Baixo risco;
* Baixa rentabilidade.

#### Tesouro Direto

* Investimento em títulos públicos;
* Considerado de baixo risco.

#### CDB

* Emitido por bancos;
* Pode oferecer rentabilidade superior à poupança.

---

### Hábitos Financeiros Saudáveis

* Registrar gastos;
* Evitar compras impulsivas;
* Poupar regularmente;
* Investir com objetivos definidos;
* Buscar educação financeira contínua.

# 4.2 Glossário

| Conceito              | Definição                                             |
| --------------------- | ----------------------------------------------------- |
| Ativo                 | Bem ou investimento que possui valor econômico        |
| Passivo               | Dívidas e obrigações financeiras                      |
| Liquidez              | Facilidade de transformar um investimento em dinheiro |
| Orçamento             | Planejamento das receitas e despesas                  |
| Renda Fixa            | Investimento com regras de rendimento conhecidas      |
| Rentabilidade         | Ganho obtido em um investimento                       |
| Reserva de Emergência | Dinheiro destinado a imprevistos                      |
| Juros Compostos       | Juros calculados sobre juros acumulados               |
| Diversificação        | Distribuição dos investimentos em diferentes ativos   |
| Patrimônio            | Conjunto de bens e recursos financeiros               |
